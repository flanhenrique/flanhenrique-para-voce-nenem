# Para Você, Neném ♡

Uma pequena aventura romântica em pixel art, feita por Henrique.

Use os botões na tela, as setas ou WASD para encontrar cinco corações. Depois, encontre o outro personagem perto da lua. O botão de som controla a música e os efeitos. A melodia instrumental é original e sintetizada no navegador.

## Rodar localmente

Execute `python3 -m http.server 8000` na raiz e visite `http://localhost:8000/`.

## Publicação

O projeto usa HTML, CSS, JavaScript e Canvas. Os arquivos são locais, e o site é estático. No repositório público do GitHub, a origem do Pages é **Deploy from a branch**, com a branch **main** e o diretório **/(root)**, disponíveis no GitHub Free.
